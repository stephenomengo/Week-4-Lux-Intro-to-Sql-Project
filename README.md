# Week-4-Lux-Intro-to-Sql-Project
# 🗄️ Nairobi Academy SQL Project

## 📌 Overview

A SQL project focused on managing and analyzing student records, subjects, and examination results using PostgreSQL.

## 🛠️ Tools

* PostgreSQL
* SQL

## 📊 Key Tasks

* Database and table creation
* Inserting, updating, and deleting records
* Filtering and sorting data
* Using `WHERE`, `BETWEEN`, `IN`, `NOT IN`, and `LIKE`
* Aggregate queries using `COUNT()`
* Conditional logic using `CASE WHEN`
* Analyzing student performance and examination results

## 🎯 Objectives

* Practice database management and SQL querying.
* Retrieve meaningful insights from student records.
* Categorize student performance using examination marks.
* Strengthen data manipulation and analysis skills.
